# shopping-bill-python
Python program that generates formatted shopping receipts.

## Features
- Accepts item names, prices, and quantities.
- Calculates item amounts and the subtotal.
- Validates prices and quantities.
- Displays a formatted receipt with the current date.

## Technologies Used
- Python
- datetime module

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run: `python shopping_bill.py`

## Purpose
Created as a beginner Python programming project to practise user input, loops, conditional statements, exception handling, and arithmetic operations.
